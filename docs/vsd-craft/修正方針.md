# VSD Craft転用実装の修正方針

## 採用構成

```text
Codex Desktop
    ↕ CDP / Codex Microイベント
Codex Deckプラグイン
    ↕ Stream Deck互換WebSocket API
VSD Craft
    ↕ メーカー標準USB制御
VSD Inside M18
```

## 維持するもの

- `src/controller.ts`以下のCodex Deck機能
- Agent、Microアクション、Joystick、Reasoning、DIFFなど既存アクション
- Codex DesktopのCodex Micro設定との同期
- 動的な`setImage`表示
- 上流ライセンスと著作権表示

## 使用しないもの

- `src/m18.ts`の18ボタン固定配置
- `m18-adapter`によるM18直接HID制御
- 独自M18常駐watcher
- 独自設定UI

これらは削除せず、従来の直接接続方式としてソースに残す。ただしVSD Craft運用時には起動しない。

## VSD Craft向け互換化

通常のStream Deck向け成果物から別のVSD Craft向け成果物を生成し、上流向けmanifestを直接壊さない。

- 出力：`dist-vsd-craft/com.simeo.codex-deck.sdPlugin`
- `SDKVersion`：VSD公式Node.js SDKに合わせて`1`
- `Software.MinimumVersion`：VSD公式Node.js 20対応版`3.10.188.226`
- `CodePathWin`：`bin/plugin.mjs`
- `CodePathMac`：`bin/plugin.mjs`
- `Nodejs.Version`：`20`を維持
- アクション定義と実行コードは通常版と共通

## インストール方針

- VSD Craftはメーカー公式インストーラーをそのまま実行する。
- 公式インストーラーをリポジトリへ再配布しない。
- Codex DeckプラグインだけをVSD Craft標準プラグインフォルダーへ配置する。
- 既存プラグインがある場合は上書き前にバックアップする。
- `Codex Deck M18.lnk`を退避し、M18直接制御プロセスを停止する。
- 通常の`Codex Deck.lnk`はCodex CDP起動用として維持する。
- macOSではVSD Craft標準保存先へ配置し、既存のCodex Deck macOS LaunchAgentを使う。
- Linux対応は追加しない。

## 実機シーン構成

- シーン1：Agent 1～6、Joystick 4方向、Reasoningエンコーダ押下、host health／切替、Usage Limit／Overview／Reset
- シーン2：公式30キーの前半15件
- シーン3：公式30キーの後半15件
- 3シーンすべての下部ボタン：左=シーン1、中央=シーン2、右=シーン3

45個の必須操作を15件×3面へ重複なく収容するため、メーカー標準デフォルトシーンは必須3面に含めない。

## 変更しない境界

- VSD Craftの実行ファイル、DLL、インストーラー内部を書き換えない。
- M18ファームウェアを書き換えない。
- Codex Desktopを書き換えない。
- VSD公式SDKをフォークして独自プロトコルを追加しない。
