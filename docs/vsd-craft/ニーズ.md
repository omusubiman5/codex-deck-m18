# VSD Craft転用実装のニーズ

## 目的

VSD Inside M18を、メーカー標準アプリのVSD Craftで設定できるCodex Micro操作デバイスとして使う。

対応OSはWindowsとmacOSに限定し、Linuxは対象外とする。

## 必須要件

- M18のUSB通信、15個のLCD表示、プロファイル管理はVSD Craftへ任せる。
- 独自のM18設定UIを作らない。
- Codex操作は上流Codex Deckが持つネイティブCodex Microブリッジを維持する。
- VSD Craftの画面からCodex Deckアクションを物理位置へドラッグして配置できるようにする。
- Agent 1～6、FAST、APPR、REJ、SPLIT、MIC、CODEX、DIFFなどを個別のアクションとして選択できるようにする。
- Agentの状態とCodex Microのキーキャップ画像を15個のLCDへ動的に表示する。
- Agent状態色はCodex Micro画面の意味に合わせ、準備完了／正常は緑、動作中は紫、選択中は青、承認待ちはオレンジ、エラーは赤、オフ／不可はグレーとする。状態変化はキー表示へ動的に反映する。
- M18下部の3物理ボタンはVSD Craft標準のシーン切替として使い、15キー×3面の45必須操作へ直接到達できるようにする。
- 既存のM18直接HID制御ランタイムとVSD Craftを同時に動かさない。
- VSD Craft本体、M18ファームウェア、USBドライバーは改変しない。
- インストール前にVSD Craft公式インストーラーの署名とESET検査結果を確認する。

## 利用イメージ

```text
VSD Craft
  ├─ 左下: シーン1（Agent／Navigation／Usage）
  ├─ 中下: シーン2（公式キー前半15件）
  └─ 右下: シーン3（公式キー後半15件）
        ↑ VSD Craft標準のScene Shiftで直接切替

各面の15個LCD
  ← VSD Craftの標準UIでアクションと表示を編集
  ← Codex DeckプラグインがCodex状態と操作を提供
```

## 完了条件

- VSD CraftがM18を認識する。
- VSD Craftのアクション一覧へCodex Deckが表示される。
- Codex Deckアクションを任意のLCD位置へ配置できる。
- 配置したAgentキーへCodex状態画像が表示される。
- 物理キー操作がCodex Desktopへ届く。
- 45必須操作が15件×3面へ重複なく収まり、下部3ボタンで各面へ直接切り替わる。
