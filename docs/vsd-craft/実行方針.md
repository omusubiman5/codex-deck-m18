# VSD Craft転用実装の実行方針

## 実行順序

1. 通常のCodex Deckプラグインをビルド、型検査、テストする。
2. 通常成果物からVSD Craft互換成果物を生成する。
3. VSD Craft互換manifestを機械検査する。
4. VSD Craft公式インストーラーのサイズ、署名、ESET結果を確認する。
5. VSD Craftを公式インストーラーで導入する。
6. `Codex Deck M18.lnk`をスタートアップから退避する。
7. M18直接制御watcher、Nodeランタイム、Rustアダプターを停止する。
8. VSD Craft標準プラグインフォルダーへCodex Deckを配置する。
9. VSD Craftを起動する。
10. M18認識、プラグイン起動、`registerPlugin`、`setImage`、キー入力を確認する。
11. VSD Craft標準UIで`Codex Micro`、`Codex Tools`の2シーンを作る。
12. 既存の`デフォルトシーン`をM18標準面として維持する。
13. 3シーンすべてで下部3ボタンを左=Micro、中央=Tools、右=標準へ設定する。

## 配置先

```text
%APPDATA%\HotSpot\StreamDock\plugins\com.simeo.codex-deck.sdPlugin
```

VSD Craftの版によって`Hotspot`または`StreamDock`直下を使う場合は、インストール後に実フォルダーを検出して決定する。

## ロールバック

- VSD Craftを終了する。
- 配置したCodex Deckプラグインをバックアップと入れ替える。
- 退避した`Codex Deck M18.lnk`をStartupへ戻す。
- 必要な場合だけ従来のM18 watcherを再起動する。

## 検証基準

- VSD公式SDKと同じ起動引数で`registerPlugin`が成功する。
- Agentアクション配置後に`setImage`が発生する。
- M18の15個LCDがVSD Craftの配置と一致する。
- 下部3物理ボタンがVSD Craft標準のシーンシフトとして3環境へ直接切り替わる。
- 旧M18アダプターが同時起動していない。
