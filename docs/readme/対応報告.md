## 3. 事実修正

### 3.1 ログ出力先（調査 3.1）

`m18.log` の出力先が固定パスであるかのような記述を訂正した。

変更前:

```text
| %LOCALAPPDATA%\CodexDeck\m18.log | watcher、Codex接続、M18接続、描画同期 |
```

変更後:

```text
| watcherスクリプトを置いたフォルダの親に生成される m18.log | watcher、Codex接続、M18接続、描画同期 |
```

加えて、常駐運用例の配置（`C:\path\to\CodexDeck\M18\`）における実際の出力先が `C:\path\to\CodexDeck\m18.log` である旨を本文に明記した。`m18-events.log` と `codex-micro-bridge.json` は記載どおりのため変更していない。

### 3.2 Windows導入の必須前提（調査 3.2）

Windows導入手順を全面的に書き直した。

追記した内容:

1. Windows版インストーラはビルドを行わないこと。
2. 事前に `npm ci` と `npm run validate:vsd-craft` の実行が必要であること。成果物が無い場合はインストーラが失敗すること。
3. インストーラが中止する3条件（manifest互換設定、Authenticode署名、ESETスキャン）。
4. 未記載だったスイッチ `-SkipEsetScan`、`-SkipVSDCraftInstall` を含む一覧表。
5. インストーラが旧方式のランタイム停止とスタートアップ退避を行うこと。
6. macOS版はスクリプトが自らビルドするため事前ビルドが不要であること。

ESET依存は必要環境にも「Windowsのみ：ESETコマンドラインスキャナ、または後述の`-SkipEsetScan`」として掲載した。

### 3.3 必要環境の分離（調査 3.3）

単一だった必要環境を方式ごとに分割した。

| 方式 | Rust / C++ツールチェーン | OS |
|---|---|---|
| VSD Craft（推奨） | 不要（明記） | Windows 10以降 または macOS |
| M18直接接続（旧方式） | 必要 | Windows 10以降 |

推奨構成側に「RustとC++ツールチェーンは**不要**です。これらが必要なのは旧方式のみです。」と明示し、不要な導入を防いだ。macOS対応がOS要件に反映されていなかった矛盾も解消した。

## 4. 調査中に判明した事項と対処

[原因調査 3.8](原因調査.md)のとおり、当初「翻訳漏れ」と判断した2つの英文は、テストで固定された帰属表記であった。

初回の再編でこれを日本語へ置き換えた結果、`npm test` が2件失敗した。

```text
✖ iPhone source-install docs state the current Mac and distribution boundary
✖ release docs preserve inspiration credit and independent implementation wording
ℹ tests 143 / pass 141 / fail 2
```

`test/release-docs.test.ts` は、iPhone配布境界の記述と上流帰属の文言を `README.md`・`docs/IOS_INSTALL.md`・`docs/RELEASE_0.7.0.md` の3文書で一致させることを要求している。

対処として、英語原文を復元したうえで日本語の補足を併記した。文言の同一性を保ちつつ、日本語読者が意味を取れるようにしている。

```text
A Mac with Xcode is required to build and install it, even when the phone will control only Windows.
（ビルドとインストールにはXcodeを導入したMacが必要で、これは操作対象がWindowsのみの場合も変わりません。）
```

```text
...ビジュアルを使ったindependent implementation（独立実装）であり、...
```

再発防止として、この保護範囲を `CONTRIBUTING.md` の「Before opening a pull request」へ項目5として追記した。

```text
5. Documentation prose is under test. `test/release-docs.test.ts` pins the iPhone
   distribution boundary and the upstream attribution wording across README.md,
   docs/IOS_INSTALL.md, and docs/RELEASE_0.7.0.md; those sentences must stay
   identical in all three, in English. Add a translation alongside the original
   rather than replacing it, and run `npm test` after any documentation edit.
```

## 6. 未対応事項

以下は今回の対応範囲外とした。

- **`m18.log` の出力先そのものの統一**: README側を実装に合わせる形で対処した。`scripts/Watch-CodexDeck-M18.ps1` を `codexDeckStateRoot()` 相当の固定パスへ変更すれば記述は単純になるが、既存利用者のログ位置が変わるため、実装変更として別途判断する。
- **`-DryRun` / `-ForceRestart` 以外のランチャースイッチ**: `docs/TROUBLESHOOTING.md` に記載のある `-InstallStartup` / `-UninstallStartup` はREADMEに未掲載のまま。旧方式の常駐運用は手動登録手順を採っているため、両者の関係整理は別作業とする。
- **同名3系統ドキュメントの統廃合**: 注記による誘導にとどめた。ファイル自体の整理は履歴保全との兼ね合いがある。
- **購入情報の価格記載**: 日付付き注記を維持したまま末尾へ移動した。定期更新か削除かは運用判断による。
