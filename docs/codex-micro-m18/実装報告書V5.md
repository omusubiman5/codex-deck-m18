# Codex Deck M18 公式30キー通常操作復元 実装報告書 V5

## 1. 結論

公式根拠のない「危険キー3種」分類を撤回し、`APPR`、`REJ`、`DEL`、`PLAY`を含む公式30キーすべてを通常の単押しで使用できる実装へ戻した。

コード、表示、README、現行テスト、実機pluginを同じ仕様へ更新した。`Rate-limit Reset`は公式30キーとは別の専用機能であり、reset credit消費を伴うため既存の1.2秒長押し確認を維持した。

## 2. 誤実装の内容

V2～V4では`APPR`、`DEL`、`PLAY`を独自に「危険キー3種」と分類し、次を追加していた。

- 1.2秒未満の短押し抑止
- release時の実行
- 赤枠警告
- 保持進捗表示
- 危険キー専用controller state
- 危険キー専用試験

この分類には公式仕様上の根拠がなかった。日常的に使用する公式キーの操作性を変更する誤実装だった。

## 3. 正しい仕様

- 公式30キーはすべて通常の単押し操作である。
- `APPR`は現在の承認操作である。
- `REJ`は現在の拒否操作である。
- `DEL`は現行実装ではチャットのアーカイブであり、Taskの不可逆削除ではない。
- `PLAY`は先頭に設定されたEnvironment Actionを呼び出す。
- `MIC`だけはCodex Microのpress／release入力を使用する。
- その他29キーはkey-downで1回実行し、key-upで追加実行しない。
- `Rate-limit Reset`の長押し確認は公式30キーと無関係であり、維持する。

- `MIC`のdown/upだけは従来どおり維持する。
- Rate-limit Resetのdown/up長押し判定は変更していない。

### 4.3 文書訂正

- テスト計画書と実機テスト実行票を修正した。
