# 実行方針: Codex Micro互換版の導入

## 手順

1. ニーズと修正境界を文書で固定する。
2. M18入力割当と短押し／長押し判定のみを修正する。
3. TypeScript型検査、既存全テスト、新規ジェスチャテストを実行する。
4. M18配布物を再ビルドする。
5. `%LOCALAPPDATA%\CodexDeck\M18`へ更新物を配備する。
6. 常駐watcherに更新版を再起動させる。
7. CDP接続、USB接続、タスク同期、実機キーイベントをログで確認する。

## 完了条件

- 15 LCDキーと下段3ボタンが「ニーズ.md」の割当どおりに構成されている。
- 短押し時はReasoning decreaseだけ、長押し時はencoder down/upだけが送られる。
- 既存テストを壊さず、新規テストも合格する。
- インストール先のNodeランタイムとHIDアダプターが起動し、Codex DesktopとM18の両方へ接続する。
- 実機ボタン入力が`m18-events.log`に記録される。
