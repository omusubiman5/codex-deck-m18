# Codex Deck M18 実機テスト実行票 V1

## 1. 原則

- 物理M18の押下だけを実押下として記録する。
- VSD Craft画面上の選択、自動dispatch試験、profile検証を物理押下の代替にしない。
- Codex、VSD Craft、plugin、watcherを試験中に再起動しない。
- 公式30キーには独自の危険分類を設けず、すべて通常の単押しで確認する。
- `Usage Limit`と`Usage Overview`は表示専用であり、押下時dispatchを期待しない。表示内容を確認する。
- 不成立は合格にせず、理由、alert、plugin接続状態、次の有効操作を記録する。

## 2. 証跡採取

試験開始直前に次を実行し、10分以内に実押下する。

```powershell
powershell -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\Capture-CodexDeck-PhysicalTestEvidence.ps1 -DurationSeconds 600
```

証跡は`%LOCALAPPDATA%\CodexDeck\live-runs`へ保存される。スクリプトは観測専用で、アプリを停止・起動しない。
