# ニーズ: M18でCodex Micro機能を使う

## 目的

VSD Inside M18を、Codex DesktopのCodex Microと同じ操作・状態表示に使う。汎用マクロパッドや独自ランチャーを作ることは目的に含めない。

## 必須要件

- Codex Deckが既に実装しているCodex MicroのCDP接続、イベント送信、状態取得、キー画像描画を維持する。
- M18とのUSB HID通信にはOSSの`mirajazz`を使う。OpenDeck、仮想HID、ファームウェア書換えは使わない。
- Agent 1～6をCodex Microの割当・状態表示と同期する。
- Codex MicroのJoystick 4方向（上・下・左・右）をすべて操作できるようにする。下方向を省略しない。
- Reasoningエンコーダ押下とReasoning effortの増減をすべて操作できるようにする。
- Codex Desktopから取得する公式30キー（`FAST`、`APPR`、`REJ`、`SPLIT`、`MIC`、`CODEX`、`BUG`、`OAI`、`TERM`、`DWN`、`DEL`、`NEW`、`NAV`、`MAGIC`、`DIFF`、`PLAY`、`GIT`、`BRCH`、`MRG`、`PR`、`PAINT`、`LAB`、`PARTY`、`TIME`、`MIND+`、`MIND-`、`SETUP`、`FOLD`、`UPL`、`APPS`）を個別アクションとして選択・実行できるようにする。
- New Task、Windows／Macホスト切替と接続状態表示、Usage Limit、5時間／週次を同時に示すUsage Overview、長押し確認付きRate Limit Resetを提供する。
- 45個の必須操作を15個のLCDキー×3シーンへ重複なく固定配置し、全件をM18内へ収容する。
- 下段3ボタンは左・中央・右をそれぞれシーン1・2・3の直接切替に使う。45操作には数えない。
- Codex Desktop起動後は常駐し、CodexやUSBの再接続後にも復帰する。

上記は今回の完了に必要な正本スコープであり、「将来対応」「追加候補」「対象外」へ移してはならない。

## 必須の3面構成

| 面 | 15 LCDキーの内容 | 個数 |
|---|---|---:|
| シーン1 | Agent 1～6、Joystick 4方向、Reasoningエンコーダ押下、ホスト切替＋health、Usage Limit／Overview／Reset | 15 |
| シーン2 | 公式30キーの前半15件 | 15 |
| シーン3 | 公式30キーの後半15件 | 15 |

下段左・中央・右はそれぞれシーン1・2・3へ直接切り替える。したがって必要数は`15 × 3 = 45`であり、下段3ボタンを加算した48操作ではない。

公式30キーにはNew TaskとReasoning effort増減を含む。3面のいずれかをメーカー標準デフォルト面へ明け渡して必須機能を30枠へ縮小してはならない。
