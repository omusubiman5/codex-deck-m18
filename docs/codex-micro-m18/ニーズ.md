# ニーズ: M18でCodex Micro機能を使う

## 目的

VSD Inside M18を、Codex DesktopのCodex Microと同じ操作・状態表示に使う。汎用マクロパッドや独自ランチャーを作ることは目的に含めない。

## 必須要件

- Codex Deckが既に実装しているCodex MicroのCDP接続、イベント送信、状態取得、キー画像描画を維持する。
- M18とのUSB HID通信にはOSSの`mirajazz`を使う。OpenDeck、仮想HID、ファームウェア書換えは使わない。
- 15個のLCDキーに、6エージェント、6アクション、Plan、Back、Forwardを表示する。
- 下段3ボタンはCodex Microと同じネイティブ環境アクション1～3に固定する。
- Codex Desktop起動後は常駐し、CodexやUSBの再接続後にも復帰する。

## 操作割当

| M18入力 | Codex Micro入力 |
|---|---|
| LCD 1–6 | Agent 1–6 |
| LCD 7–12 | Fast / Approve / Reject / Fork / Dictation / Send |
| LCD 13 | Joystick Up: Plan |
| LCD 14 | Joystick Left: Back |
| LCD 15 | Joystick Right: Forward |
| 下段左 | Codex `environmentAction1` |
| 下段中央 | Codex `environmentAction2` |
| 下段右 | Codex `environmentAction3` |

下段3ボタンはM18内のページやプロファイルを切り替えず、Codex Desktop側に登録された環境アクションを実行する。
