# VSD Inside M18 setup

This mode runs Codex Deck directly against the M18. OpenDeck and Elgato Stream Deck are not required.

## Requirements

- Windows 10 or newer
- Codex Desktop
- Node.js 20 or newer
- VSD Inside M18 identified as `VID 0x5548 / PID 0x1000`

## Run

From the built `dist\m18` directory:

```powershell
.\Start-CodexDeck-M18.ps1 -DryRun
.\Start-CodexDeck-M18.ps1
```

`-DryRun` only inspects the Codex bridge state and enumerates the M18. The normal command starts or reuses the upstream Codex Deck loopback-only CDP launcher, then starts the M18 runtime.

If Codex is already open without the bridge, close it normally and run the command again. `-ForceRestart` is available only when an explicit immediate restart is wanted.

Stop the runtime with Ctrl+C. This closes the adapter but does not modify firmware, drivers, or the Codex installation.

The installed startup entry uses `Watch-CodexDeck-M18.ps1`. It keeps one runtime instance alive and reconnects after Codex or the USB device is restarted. Diagnostics are written to `%LOCALAPPDATA%\CodexDeck\m18.log`.

## Three-scene layout

| Scene | LCD actions |
|---|---|
| 1 | Agent 1–6, joystick up/down/left/right, encoder click, host target/health, Usage Limit, Usage Overview, Rate Limit Reset |
| 2 | Official keycaps `FAST` through `DIFF` |
| 3 | Official keycaps `PLAY` through `APPS` |

The bottom-left, bottom-middle, and bottom-right keys select scenes 1, 2, and 3 directly. They are navigation controls and are not counted among the 45 LCD actions.

## Build

With Node.js 20+, Rust stable and the normal Windows C++ build prerequisites:

```powershell
npm ci
npm run check
npm test
npm run build
npm run build:m18
```

The output is `dist\m18`. The adapter uses `mirajazz` 0.9.0 and accepts only the verified M18 HID interface.
