# Codex Micro iPhone UI 実装報告書 V1

## 1. 実装結果

添付された画面イメージをiPhoneアプリ全体の画面参照として、起動画面を4タブ構成へ変更した。旧Dashboardは削除せず残しているが、アプリ起動時には使用しない。

- Control：Agent 6件を3列×2段、Micro Actions 6件を6列×1段で表示
- Palette：公式30キーを5列×6段で表示し、カテゴリ絞り込み、詳細、実行、削除確認を実装
- Usage：自動／5時間／週間／その他の切替、利用枠カード、1.2秒長押しResetを実装
- Hosts：Windows／Mac切替、Host一覧、選択Host詳細、再接続、接続テスト、設定導線を実装
- 共通：濃紺ヘッダー、白系キャンバス、下部4タブ、明示的な文字・アイコン・状態色を実装

## 2. 状態表現

Agent状態は画面参照に合わせ、次の意味で統一した。Paletteのキー色はキー種別を示す固定色であり、Agent状態色とは別に扱う。

| 状態 | 色 | 併記する表示 |
| --- | --- | --- |
| 正常／完了 | 緑 | 準備完了／完了＋チェック |
| 動作中 | 紫 | 動作中＋稲妻 |
| 選択中 | 青 | 選択中＋チェック |
| 承認待ち | 橙 | 承認待ち＋手 |
| エラー | 赤 | エラー＋警告 |
| オフ／不可 | 灰 | 停止中＋停止記号 |
