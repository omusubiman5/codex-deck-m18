# Codex Micro iPhone UI 実装計画書 V1

## 1. 正本

- 画面参照：`ChatGPT Image 2026年8月19日 14_45_15.png`
- 実装対象：`ios/CodexDeckMobile`
- 維持対象：既存Relay、Agent統合、公式30キー、Usage取得、Reset、Host診断、Keychain／TLS境界

画像はM18配色見本ではなく、iPhoneアプリの4画面、情報配置、操作方式、状態表現を示す画面参照として扱う。

## 2. 差異

現行は単一Dashboardと複数sheetで構成され、中央に立体的なMicroデバイス模型を表示している。参照画面はControl、Palette、Usage、Hostsの常設4タブで、平面的なカードへ情報を明示する。Agent名が7.1ptの物理キー内に入る現行表示は参照画面と一致しない。

## 3. 実装範囲

### Control

- 濃紺ヘッダーに`Codex Micro`と接続状態を表示する。
- Windows／Macのターゲット切替を上部へ置く。
- Agent 1～6を3列×2段カードで表示する。
- 各Agentに番号、名称、状態チップ、進捗、ホスト、選択状態を文字・アイコン・色で表示する。
- Micro Actions 6件を6列×1段の色付きカードで表示する。
- Joystick 4方向とReasoning増減を独立操作として表示する。

### Palette

- 公式30キーを5列で表示する。
- `すべて`、`アクション`、`ナビゲーション`、`開発`、`その他`で絞り込む。
- キーはカテゴリごとの固定色を使い、Agent状態色と混同しない。
- 選択キーのID、名称、カテゴリ、用途、互換対象を下部へ表示する。
- タップで選択、実行ボタンで送信する。破壊操作は確認する。

### Usage

- `自動`、`5時間`、`週間`、`その他`のモードを表示する。
- 利用枠ごとに残量、期間、リセット時刻、ホスト、鮮度をカード表示する。
- Resetは赤い大型ボタンを1.2秒長押しした場合だけ実行する。
- 長押し進捗と実行可能／不可を文字でも表示する。

### Hosts

- Windows／Macターゲット切替、Host一覧、選択Host詳細を1画面へ集約する。
- 接続状態、最終更新、Codex版、Relay状態を文字と色で表示する。
- 再接続、接続テスト、詳細、設定への導線を設ける。

## 4. 共通仕様

- 下部4タブを常設する。
- 参照画面に合わせ、白系キャンバス、濃紺ヘッダー、小さめの角丸、明確な境界線を使う。
- 状態色は正常／完了=緑、動作中=紫、選択中=青、承認待ち=橙、エラー=赤、オフ／不可=灰とする。
- 色だけに頼らず、状態文字とSF Symbolsを併記する。
- 本文は原則12pt以上、Agent名は14pt以上とする。

## 5. 検証

- `TabView`に4タブが存在する。
- 公式30キーがカタログから欠落なく表示される。
- Agent状態の意味と色が一致する。
- Resetは1.2秒未満で実行されない。
- 既存のRelay command、Host routing、Usage sourceを再利用する。
- TypeScript側回帰試験とiOS静的検査を通す。

## 6. 完了条件

参照画像の4画面構成、主要情報、主要操作、状態表現が実装へ対応し、旧立体デバイスDashboardがアプリの起動画面ではなくなっていること。
