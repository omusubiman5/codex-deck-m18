# ニーズ：VSD Craftへのブリッジ統合

2026-09-09

## 目的

VSD CraftでCodexのボタンを使うために、ユーザーが別のブリッジアプリや専用ショートカットを起動したり、AIへ復旧を依頼したりする必要をなくす。

## ユーザーの要求

- ブリッジの起動・接続・再接続をVSD Craftのプラグインに統合する。
- VSD Craft起動時、Codexが未起動なら接続可能な状態で起動する。
- Codexが通常起動済みでも、VSD Craftの設定画面から接続を復旧できる。
- 接続状態と必要な操作が画面上で分かる。ログを見ることを前提にしない。
- 切断中の使用量・リセット残数を最新値のように表示しない。
- ボタン割当、既存設定、Macとの連携を維持する。
- 統合後は旧ランチャー・直接接続ランタイム・専用ショートカット・別の自動起動登録を稼働場所から撤去する。VSD CraftのショートカットはVSD Craft本体を起動する。
- サブエージェントは使用しない。

## 対象と制約

今回の実装対象は使用中のWindows版VSD Craft。Mac版とM18直接接続方式の起動動作は変更しない。Codex本体やユーザーのタスクデータは改変しない。

現行CDP方式では接続口のない起動済みCodexへの接続に再起動が必要になる。この場合だけVSD Craftから開く確認画面でユーザーが再起動を選ぶ。作業中のCodexを自動で強制終了しない。
