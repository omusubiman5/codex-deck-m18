# 実行方針：VSD Craftへのブリッジ統合

## 実施順序

1. ニーズと修正方針を文書化する。
2. 接続マネージャー、ランチャーの状態取得、設定画面からの復旧を実装する。
3. 未接続時の使用量・残数の無効化を実装する。
4. 自動起動、再利用、通常起動済み、取り消し、多重要求、切断時の表示を検証する。
5. 型検査・テスト・VSD Craftビルドとパッケージ検証を実行する。
6. 現行プラグインをバックアップし、修正版を配置・再読み込みする。Codexプロセスを維持したことと接続・使用量の取得を確認する。
7. 実行結果と未検証事項を同じ文書へ記録する。

## 合格条件

- 専用ショートカットをユーザーの通常手順に要求しない。
- VSD CraftのCodexボタン設定から接続・復旧へ到達できる。
- 起動済みの正常なCodexは終了しない。
- 再起動確認の取り消しでCodexを変更しない。
- Codex終了後に自動起動を繰り返さない。
- 取得不能時は古い使用量・残数を最新値として表示しない。
- 既存テストと配布物検証を通過する。

## 実機検証の扱い

実行中タスクを止める再起動と物理押下を実施していない場合は、模擬検証と区別して明記する。自動確認できた接続状態だけで全ボタンの動作確認完了とはしない。

## ユーザーの操作

通常はVSD Craftを起動する。Codexが未起動ならプラグインが起動する。未接続ならVSD CraftでCodexのボタンを選び、設定欄の **Codex 接続 → 接続・復旧** を押す。通常起動済みCodexの再起動が必要な場合は、その操作で確認画面が表示される。AIへの依頼や専用ショートカットは不要。
