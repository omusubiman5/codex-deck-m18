Codex Deck for VSD Craft - macOS

1. Extract this ZIP completely.
2. Control-click "Install Codex Deck.command", choose Open, and confirm.

If VSD Craft is missing, the script can download its current PKG directly from
the official VSDinside server. It verifies the Apple package signature before
opening Installer. Run Codex Deck again after the vendor installation finishes.
The official app is never copied into this community archive.

The installer closes VSD Craft, backs up an existing plugin and launcher under
~/Library/Application Support/CodexDeck/backups, installs the bundled plugin
and Codex launcher, and restarts VSD Craft. This community package does not
contain the official VSD Craft app.

The installer is not notarized or code-signed. Verify the archive SHA-256 value
against SHA256SUMS.txt published with the GitHub release before running it.
